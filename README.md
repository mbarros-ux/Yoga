## Sobre
Site simples de yoga desenvolvido com HTML, CSS e JavaScript puro. Este projeto foi criado para praticar conceitos básicos de desenvolvimento front-end, incluindo layout responsivo e estruturação semântica.

O site apresenta uma interface limpa e minimalista, com seções de apresentação e informações sobre práticas de yoga.

## Tecnologias Utilizadas
- HTML5 - Estrutura semântica
- CSS3 - Estilização e layout responsivo
- JavaScript - Interatividade básica

## Funcionalidades
- Layout responsivo (adapta-se a diferentes tamanhos de tela)
- Navegação entre seções
- Interface otimizada para mobile e desktop
- Código organizado e semântico

## Como Executar

1. Clone este repositório:
```bash
git clone https://github.com/mbarros-ux/Yoga.git
```
2.Abra o arquivo ```index.html``` em seu navegador.
